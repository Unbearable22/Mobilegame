Все 10 уровней проиграны программно через GameManager в трёх графических прогонах, а также через solver/GridManager в тестах. Решения занимают соответственно **1, 1, 4, 1, 4, 2, 1, 2, 4, 6 действий**. Порядок обучения: источник → normal → поворот → splitter → blocker → battery за два запуска → одновременные импульсы → два источника → настройка развилки → комбинация за один запуск.

Экспертная оценка: первые уровни намеренно очень короткие демонстрации; 3 и 5 похожи по повороту, но 5 добавляет обход блока. Финал теперь действительно проверяет настройку нескольких узлов. Объективных непроходимых задач не найдено. Выводы «интересно/скучно», время решения и сложность не подтверждены тестами с людьми — следующий шаг: наблюдаемый плейтест 5–10 новичков. Не выдаём автоматическое прохождение за ручную игру на телефоне.
