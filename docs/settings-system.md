# Settings system v0.2.0

- `SettingsManager` — типизированный API предпочтений и сигнал `changed(key)`. `sound_enabled/set_sound` используют **тот же** `ProgressionManager.data.sound`; копии состояния нет.
- `ProgressionManager` владеет прогрессом и вызывает `SaveManager`. Формат JSON v1 не изменён; существующие `last_level`, `completed`, `sound` сохраняются. Миграция не требуется и прогресс не сбрасывается.
- `UIManager` строит модальный интерфейс и подписан на settings.changed. Выключение немедленно вызывает AudioStreamPlayer.stop; `_on_feedback` всегда проверяет SettingsManager. Старые отдельные sound-кнопки удалены из меню/паузы/нижней панели.
- Шестерёнка — собственный SVG, верхний правый угол с safe-area отступами, 144×144 единицы макета (48dp при ширине телефона360dp). В игровом header зарезервировано место после звёзд; пересечение проверено тестом.
- Настройки содержат SFX, версию и в debug — диагностический флаг. Музыка/вибрация и фиктивные переключатели отсутствуют. Будущие языки/quality/accessibility добавлять типизированными методами Manager, отдельными save-полями с валидацией и при необходимости миграцией версии; UI не должен самостоятельно записывать файлы.
- Открытие запоминает `settings_return_screen`, приостанавливает model/tween и блокирует поле. Закрытие/Android Back восстанавливает меню, игру, паузу или результат. Фоновые кнопки не получают фокус. При сворачивании в ходе fade-out возврат в игру превращается в возврат к паузе.
- Панель плавно появляется/исчезает. Повторный Back во время закрытия не создаёт повторных callback. Фокус возвращается шестерёнке на меню/игре, экран паузы/результата выбирает свою основную кнопку.
- Неуспех сохранения виден через существующий warning HUD; SFX preference остаётся общим на всех уровнях. Debug-диагностика не сохраняется и не доступна release.

Регрессии проверяют меню/игру/паузу/победу, открытие/закрытие native touch/Back, звук во время воспроизведения, отсутствие SFX при выключении, сохранение/пересоздание сцены, общую настройку между уровнями, сворачивание во время fade-out, геометрию шестерёнки.
