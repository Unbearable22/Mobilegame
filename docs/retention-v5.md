# Локальные системы0.5.0

Вся информация хранится на устройстве. Нет идентификатора игрока/устройства, контактов, геолокации, абсолютных дат, сети или стороннего SDK. Рост удержания пока не измерялся: это функциональность для будущего плейтеста, а не подтверждение эффекта на D1/D7.

## Достижения

| Название | Условие |
|---|---|
| Первая искра | Победа на уровне1 |
| Инженер | Все10уровней главыI |
| Переплетение | Все10уровней главыII |
| Мастер цепей | Три полностью пройденные главы |
| Парадокс | Все10уровней главыIV |
| Идеальная глава |30звёзд в одной главе |
| Созвездие |50звёзд |
| Коллекционер |100звёзд |
| Сингулярность | Все50уровней |
| Абсолютное совершенство |150звёзд |

Экран открывается из главного меню; по3карточки на странице,10карточек всего. У каждой собственный ID, пиктограмма, название, условие, счётчик и полоса прогресса, состояние. Полученные ID сохраняются однократно; повторная победа/Undo/restart/recreation не выдаёт достижение снова. Старые победы/звёзды ретроспективно дают соответствующие достижения без очереди всплывающих сообщений. При новой выдаче после победы показывается уведомление; несколько одновременных выдач объединяются в первое название и +N, полный список доступен на экране.

## Темы

Neon доступна сразу. Electric Blue требует все10побед главыI, Violet Pulse —II, Emerald Circuit —III, Solar Gold —все50побед. Просто посещённая или восстановленная из старого save открытая глава не даёт тему. Выбор сохраняется; неизвестная/недоступная тема заменяется Neon. Меняются акценты UI, узлов и энергии; тёмные поверхности и светлый текст сохраняют контраст. Силуэты/стрелки/замки/деления/галочки сохраняются. Палитры не передаются ReactionEngine и не меняют модель.

## Уменьшение эффектов

Переключатель находится в настройках и сохраняется. Он останавливает движение/моты/ореолы декоративного меню, бегущие импульсы/кольца касания/зарядные вспышки поля; энергия и состояние остаются видимыми статически. Звёзды сразу показывают итог; fades/появление награды становятся статическими. При включении во время активной анимации существующие tweens завершаются/отменяются немедленно. Таймер скрытия статического уведомления остаётся, игровая последовательность волн и её правила не меняются.

## Определения статистики

Статистика агрегирована по уровням и не является сырым журналом сессий.

- `attempts`: новая попытка начинается с первого принятого поворота/запуска после выбора уровня или Restart. Само открытие игры/меню/списка не добавляет попытку.
- `restarts`: принятые нажатия Restart, включая сброс ещё нетронутого уровня.
- `launches`, `rotations`, `undos`: фактически принятые действия, в том числе повторные действия после Undo. Отмена не вычитает уже сделанную работу из аналитики; игровая история и бюджет отменяются как прежде.
- `active_seconds`: время после первого действия в активной игре, включая планирование и реакцию. Меню, overlays, пауза и фон исключены. Частичная попытка тоже входит в общее время.
- `best_stars`, `best_launches`, `best_seconds`: лучшие показатели реальных побед; до победы нули. Минимум времени/запусков и максимум звёзд — независимые агрегаты, могут относиться к разным победам.
- `wins`/`losses`: первый конечный исход каждой попытки. Undo продолжает ту же попытку: повторный исход не увеличивает эти счётчики, но последующая победа улучшает лучшие показатели. Поэтому исправленная через Undo первая неудача может иметь `best_stars>0` при `wins=0` — метрика хранит первый исход, а не окончательный успех уровня.
- `last_played_level`: последний уровень с принятым игровым действием,0при отсутствии; отличается от сохраняемого `last_level`, который означает последний выбранный доступный уровень для Continue.

Счёт времени идёт в памяти; записи выполняются на переходах/паузе/фоне/результатах/экспорте, не каждый кадр. При аварийном уничтожении процесса без lifecycle-события работа после последней записи может не сохраниться. Незавершённая попытка не восстанавливается после запуска приложения; это прежнее правило кампании.

## Экспорт

Настройки → Локальная статистика → Экспорт JSON. Файл **`user://chain-react-statistics.json`** создаётся атомарно, рядом временно используется `.tmp`. JSON показывается в прокручиваемом поле; кнопка «Скопировать JSON» позволяет вставить его в локальный файл. Экспорт содержит только allowlisted числовые агрегаты50уровней и последний сыгранный номер. При отсутствии попыток нет фиктивных записей.

Это внутренний каталог приложения, не общая папка Downloads/Android share sheet; дополнительных разрешений нет. Для debug APK файл также доступен через `adb exec-out run-as org.chainreact.onetappuzzle cat files/chain-react-statistics.json`. Перед использованием adb проверить путь через `find files -name chain-react-statistics.json`.

## Сохранения

Формат3 читает1/2/3. Перед миграцией v0.4.0(формат2) сохраняется исходная **`.v2.bak`**, v1—`.v1.bak`; запись основного JSON атомарная. Пройденные уровни, лучшие звёзды, SFX, последний выбранный уровень/текущая глава и ранее открытые главы сохраняются. Ошибочные необязательные поля достижений/тем/статистики очищаются независимо от корректного прогресса. Некорректный/будущий основной формат сохраняется в `.corrupt` по прежним правилам.

Совместимость JSON не означает совместимость debug-сертификата CI. Прежний приватный CI-ключ недоступен; при конфликте подписей сначала выполнить [backup/восстановление прогресса](android-progress-transfer.md). Ни ключи, ни release-пароли в Git не добавлены.

Экспорт статистики не заменяет backup `progress.json`: для переноса звёзд/глав/достижений/тем нужен полный файл сохранения.
