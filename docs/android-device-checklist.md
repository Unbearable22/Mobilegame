# Ручная проверка Android debug APK

Статус старого APK: пользователь подтвердил работу меню, прочих кнопок, сохранений и отсутствие критических проблем производительности, но сообщил о неработающих поворотах. **Новый APK 0.2.0 на физическом устройстве ещё не проверен.** Заполнить модель, версию Android, размер/плотность экрана, SHA256 APK, результат и logcat для каждого сбоя.

## Установка

- [ ] ARM64, Android 7.0 / API 24 или новее. Скачать APK и сверить SHA256 из того же артефакта.
- [ ] Установить через файловый менеджер (разрешить установку этому источнику) или `adb install -r chain-react-debug-arm64.apk`.
- [ ] Проверить иконку и название в launcher, запуск офлайн, отсутствие запросов разрешений.
- [ ] Если подпись предыдущей debug-сборки отличается, установка поверх неё невозможна. Сначала сохранить результаты тестирования; удаление приложения удалит локальный прогресс. Локальные повторные сборки используют один debug-ключ, чистые CI runners создают новый.

## Управление и игровой процесс

- [ ] Касание источника запускает ровно одну реакцию; быстрый двойной тап и несколько пальцев не обходят бюджет.
- [ ] Поворот до запуска, запрет поворота после запуска; кольцо касания и стрелки соответствуют действию.
- [ ] Пройти уровни 1–10; отдельно проверить батарею двумя запусками (6) и одновременными импульсами (7/10).
- [ ] Undo восстанавливает и заряды, и стрелки, и бюджет; Undo из поражения позволяет повторить попытку.
- [ ] Restart во время реакции исключает позднюю победу/изменение нового поля.
- [ ] Pause замораживает импульсы, Continue продолжает. Next Level открывает правильный уровень; после 10 — первый.
- [ ] Выбор уровней из меню/паузы/результата, возврат к исходному диалогу; звук переключается и сохраняется.

## Системные события и сохранения

- [ ] Аппаратный Back и жест Back открывают/закрывают паузу; в главном меню не завершают приложение неожиданно.
- [ ] Home → возврат во время реакции: игра остаётся на паузе; Continue не создаёт лишнюю волну.
- [ ] Блокировка/разблокировка, входящий звонок, переключение приложений: нет неконтролируемого запуска и фонового звука.
- [ ] После закрытия/принудительной остановки и нового запуска сохранены выбранный уровень, лучшие звёзды и звук. Незавершённая попытка не сохраняется по текущему дизайну.
- [ ] Установка обновления с тем же debug-ключом сохраняет прогресс.

## Экраны и доступность

- [ ] Портретная ориентация не меняется при повороте устройства. Проверить 16:9 и вытянутый экран, вырез/камеру и жестовую навигацию.
- [ ] Меню, поле, победа, поражение, уровни и пауза: текст читается, кнопки нажимаются пальцем, нет обрезки под вырезом или системной панелью.
- [ ] Android увеличенный размер текста/дисплея; свет/темнота, громкость/беззвучный режим, гарнитура.

## FPS и нагрев

- [ ] До старта зафиксировать заряд, температуру и состояние энергосбережения.
- [ ] Наблюдать 10 минут обычной игры и многократных перезапусков 10-го уровня: целевой FPS 60, зафиксировать реальные FPS/время кадра и рывки.
- [ ] Повторить при энергосбережении, после сворачивания и при низком заряде. Зафиксировать нагрев/троттлинг, расход батареи и память.
- [ ] Сохранить `adb logcat` при сбоях. В debug-сборке замеры ориентировочные; финальную производительность сравнивать на release-профиле позже.

## Обязательный повторный тест 0.2.0

- [ ] Шестерёнка из меню/игры, native Close и системный Back, SFX off немедленно прекращает звук и сохраняется после перезапуска.
- [ ] На уровне3 до запуска: четыре касания стрелки с дугой дают четыре поворота, затем исходное направление; Undo/Restart; на уровне9 проверить splitter.
- [ ] После запуска поворот запрещён с понятным сообщением; после полного Undo или Restart снова доступен.
- [ ] Settings во время реакции → Back; Home во время закрытия Settings → возврат остаётся на паузе.
- [ ] При неработающем повороте включить debug-журнал и собрать данные по [android-touch-debug.md](android-touch-debug.md).
- [ ] Перед сменой debug-подписи сделать резервную копию прогресса через `adb shell run-as org.chainreact.onetappuzzle find files -name progress.json` и `adb exec-out run-as ... cat <найденный путь>`. CI debug-ключ меняется на чистых runners; удаление приложения ради установки APK с другой подписью удаляет прогресс. Не удалять старую игру до сохранения данных. Это ограничение подписи, не миграции JSON.
